# Scientific approach illustration

`top-down-bottom-up.svg` redraws Figure 1.1, "Conceptual steps of top-down and bottom-up climate risk
assessment approaches", in the CST Toolbox Technical Note (2025). The reference is
`docs/references/cst-toolbox-technical-note-2025.md`, Section 1; the original image was inspected in
`knowledge:sources/tools/_images/cst-toolbox-technical-note-2025/image1.png` because the repository's
converted reference has a missing image target. The editable SVG preserves both four-step sequences,
with minor grammar and wording edits. White fills, neutral borders and the site's system font replace
the original blue and green gradients. The surrounding prose explains the role of projection context;
the website displays the diagram without a caption.

`climate-stress-test.png` reproduces the illustration in the "What is a climate stress test?" box in
Section 1, page 9 of the user-supplied `CST Development Phase Report_CLEAN_Feb14_2025 V2.docx`.
The embedded source is `word/media/image2.wmf` (relationship `rId9`).

preserving its aspect ratio and original content. No labels or plotted values were altered.

period are schematic. This illustration is not evidence of a new simulation or a basin-specific result.
