**BOUNDARY — do not chase the scope doc's last success criterion.** Scope §6
lists *"a repository-wide grep for `cst_` returning nothing outside the migration
record"*. **That is not satisfiable and must not be attempted.** P2 established
that `cst_` has three meanings: the package `blueearth_cst` (889 occurrences),
the member token (renamed), and WF2's netCDF provenance attributes
(`cst_calendar`, `cst_raw_digest`, …) which are part of WF2's on-disk output.
Frozen migration maps and every record keep the old token deliberately. The
satisfiable form, and the one to use, is P2's:

    git grep -nE "cst_[0-9{]" -- Snakefile_climate_experiment blueearth_cst config tests

with the deliberate residuals listed in
`migration_indicator-tables.md` § *Unchanged, deliberately*.
