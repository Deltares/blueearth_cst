# R09 declared-tier inventory --- the paths the three Snakefiles' `output:`
# declarations produce, expanded over the seed config.
#
# Ruled in dev/milestones/r09/migration_project-tree.md, *The inventory the map
# is validated against*: two tiers. This is the DECLARED tier -- regenerable in
# a task worktree, costs seconds, writes nothing under a production
# `project_dir`. The OBSERVED tier (one clean three-workflow run from the
# primary checkout, snapshotted as a sorted path list) is an owner action and
# is the only tier carrying undeclared engine artifacts (`hydromt.log`,
# `staticgeoms/*`, `run_default/*`, `evaluation/*`, `_work/*`, Wflow's
# `log.txt`, weathergenr's plots and date tables).
#
# Paths are project-root-relative, POSIX separators, sorted, deduplicated.
#
# PROVENANCE
#   config      config/workflows/snake_config_model_test.yml (the tracked
#               baseline seed), with `project.project_dir` repointed at an empty
#               temp dir so every job is planned rather than skipped as
#               up to date.
#   wildcards   experiment_name: experiment; realizations_num: 2;
#               stress_test temp.step_num: 1, precip.step_num: 2
#               -> 6 `cst_<c>` members per realization (cst_0 is the
#               unperturbed baseline, generated but not run through Wflow);
#               clim_project cmip6; 3 models x {historical, ssp245, ssp585}
#               x r1i1p1f1; clim_historical era5; historical_window
#               2000-01-01..2020-12-31 -> store key era5_20000101_20201231.
#   staging     WF2 and WF3 declare two WF1 outputs as `ancient(...)` inputs
#               Snakemake will not build itself, so both are staged in the temp
#               project_dir before the summary runs (same two leaves as
#               tests/test_cli.py's `config_with_staged_region` fixture):
#                 hydrology_model/staticgeoms/region.geojson
#                 config/runs/snake_config_model_creation.yml
#
# REGENERATE (from the repo root, inside pixi; $P = an empty temp dir, $C = a
# copy of the seed config with project.project_dir repointed at $P):
#   snakemake all -c 1 -s Snakefile_model_creation      --configfile $C --summary
#   snakemake all -c 1 -s Snakefile_climate_projections --configfile $C --summary
#   snakemake all -c 1 -s Snakefile_climate_experiment  --configfile $C --summary
# then take column 1 of each (tab-separated, minus the header line), strip the
# `$P/` prefix, sort -u. Regenerated under a different config the list changes:
# the member count, the model list and the store key are all config-derived.
#
# NOT BYTE-REPRODUCIBLE ACROSS TEMP DIRS. The three `config/runs/<workflow>/`
# bundles are named by a hash over the PARSED CONFIG, which includes
# `project.project_dir` -- so regenerating into a different $P changes exactly
# those three path components and nothing else (measured 2026-08-04:
# config/runs/climate_projections/61868971c618 -> 407f4256c490). The falsifier's
# assertions normalize that segment to `<digest>`; do not read the digests here
# as stable identifiers.
#
# CONSUMED BY
#   tests/test_r09_path_map.py  (the declared-tier falsifier)
#   python dev/scripts/semantic_tree_diff.py --check-map <this file> \
#       --milestone r09 --experiment-name experiment \
#       --dataset-key era5_20000101_20201231 [--r09-gap-rules]
