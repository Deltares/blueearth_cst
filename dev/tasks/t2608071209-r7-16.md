## RULED 2026-08-17 — stay unpackaged

> **Ruling (owner).** `blueearth_cst` is **not** an installable Python package;
> `pyproject.toml` stays tool-config-only. Recorded as
> `dev/decisions/0008-ship-blueearth-cst-unpackaged.md`.

O-16 therefore resolves to **"drop it"** rather than "give it a job":
`flit = ">=3.2"` (`pixi.toml:16`) is removed, because the job it was declared for
is one this repo has now decided not to have.

**The removal is not a one-line edit.** It re-solves the environment, so
`pixi.lock` must be regenerated **through pixi** — never hand-edited — and CI
runs with `locked: true`, so a stale lock fails both platform legs. Inspect the
lock diff before committing: a re-solve can carry unrelated version bumps in
with it, and those are a separate change that should be seen rather than
absorbed.
