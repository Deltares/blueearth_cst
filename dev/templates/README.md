# Developer templates

Reusable starting points for reports, review interfaces, and lane status. Copy a report template into
the owning checkout's task scratch before populating it; tracked templates contain no session-specific results.
See [scratch placement](../reference/dev-repository-layout.md#task-temporary-material) for the destination.

| Template | Usage |
|---|---|
| [lane-status.md](lane-status.md) | Copy to local root `STATUS.md`; see private citation below. |
| [workflow-report.html](workflow-report.html) | [Manual workflow report guide](workflow-report.md) |

Private-checkout-only citation: lane status (`../reference/private/dev-task-and-session-workflow.md#lane-status`).

Keep interface structure and field instructions here. Scientific figure conventions belong in
[plot style](../reference/toolbox-plot-style.md); retained reports belong with their evidence, not in this folder.
